## Objective

Write and read the three save slots with a deliberate format, round-trip
behavior, and safe handling of missing or malformed data.

## Value / context

Persistence is where the rewrite becomes a real application and where the C
version's fragile single-line format and shallow copies have user-visible
consequences.

## In scope

- Save-file location under the chosen path policy.
- Serialization of the state required to resume a round.
- Deserialization of all three slots.
- Missing-file initialization.
- Malformed-record validation and default recovery.
- Round-trip checks for names, score, geometry, status, and brick health.

## Out of scope

- Save-screen rendering and interaction.
- High-score file format.
- JSON or another external format unless selected in the decision ledger.

## Requirements

- A written state can be loaded into an equivalent in-memory state.
- One bad slot does not silently corrupt the other slots.
- Missing or malformed data follows an explicit recovery policy.
- The format decision is recorded, including whether compatibility with the C
  file is required.
- File failures are reported through the application policy.

## Acceptance criteria

- A round-trip check passes for representative full slot data.
- A missing file produces the documented default state.
- A malformed line/record produces the documented safe slot state.
- Names and all brick health values survive a successful round trip under the
  chosen format.

## Verification

- Run focused serialization checks.
- Manually alter or truncate one slot and confirm isolated recovery.
- Relaunch the application after writing a slot and inspect loaded state.

## Dependencies

BRK-019.

## Risks and decisions

Resolve the save-format and path decisions before implementation. Do not import
the incompatible legacy high-score rows from the original assets.

## Stop conditions / escalation

Stop if the chosen format cannot represent names or malformed-state recovery
without an unbounded parser. Escalate before adding a serialization library.
