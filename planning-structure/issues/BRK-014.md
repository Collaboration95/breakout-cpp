## Objective

Make the carried-over font usable for measured and visible text without leaking
font, surface, or texture resources or terminating the application from a draw
helper.

## Value / context

Text is required for the HUD, screen titles, menus, names, and scores. It is
also a valuable ownership boundary because each rendered string may involve
multiple native resources.

## In scope

- Font subsystem initialization and shutdown.
- Loading the documented font asset.
- Rendering a string in the documented black text style.
- Measuring and positioning text for later centering/layout.
- Failure reporting when font or text creation fails.

## Out of scope

- Final screen layouts.
- Text-input event handling.
- A cache or localization system unless the learner chooses one after the basic
  path works.

## Requirements

- Text can be rendered at more than one documented size.
- Temporary native resources are released after rendering.
- A missing font or failed text conversion is reported through the application's
  error policy rather than an unconditional process exit in a helper.
- The text boundary does not expose ownership of its temporary resources to
  callers.

## Acceptance criteria

- A manual run displays a known test string at a known location.
- At least one measured/centered placement is visibly correct.
- Repeated rendering does not grow native resource usage without bound.
- A font-loading failure follows the chosen application failure policy.

## Verification

- Render short and long strings at the title and small-text sizes.
- Repeat the render path for a short period and inspect for obvious leaks.
- Compare font asset and sizes with `docs/04-constants-and-layout.md`.

## Dependencies

BRK-013.

## Risks and decisions

The cache mentioned in the broad roadmap is optional. Do not make caching a
prerequisite for basic text correctness. Resolve the error policy if it changes
whether the app can run without the font.

## Stop conditions / escalation

Stop if text rendering requires screen-specific layout rules or if native text
resource ownership cannot be described clearly.
